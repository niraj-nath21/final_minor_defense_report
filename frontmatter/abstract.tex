\frontchapter{ABSTRACT}

This project implements the NeuroEvolution of Augmenting Topologies (NEAT)
algorithm to develop an autonomous agent capable of playing Super Mario Bros.
Unlike standard Deep Reinforcement Learning (DRL) approaches that rely on
computationally expensive pixel processing and fixed neural architectures, our
system evolves both the connection weights and structural topologies
dynamically. By integrating the stable retro emulator and extracting real-time
RAM states for spatial quantization, we created an efficient, dockerized
pipeline that achieves robust platforming behaviors without requiring high-end
GPU hardware. The project successfully demonstrates the viability of structural
complexification for real-time video game control, with continuous automated
reporting and metric tracking throughout the training pipeline.

AI, Dockerization, NEAT, Neuroevolution, RAM Extraction, Stable Retro, Super Mario Bros
